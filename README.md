# Ещё одну.

Браузерная игра на русском: шахматы на шестиугольной доске против соперника, который не умеет проигрывать. Нужно одержать **10 побед суммарно**. Поражения и ничьи не сбрасывают счёт.

Первый раунд — короткая обучающая позиция с матом в один ход. Затем начинаются полноценные партии, а компьютер играет всё сильнее. После третьей **сыгранной** партии соперник злится и объявляет изменение правил.

## Запуск

Нужен Python 3. Для самой игры Node.js и установка зависимостей не требуются.

```bash
python3 -m http.server 8080 --directory dist
```

Откройте <http://localhost:8080>. Ссылка на HTML через `file://` не подходит для ES-модулей и Web Worker.

Для проверки кода нужен Node.js 20+:

```bash
npm ci
npm test
npm run check
```

## Как играть

Вы играете белыми. Нажмите на фигуру, затем на подсвеченную клетку. Кнопка «Подсказка» показывает рекомендуемый ход, но не делает его за игрока. Цель партии — мат; короли не захватываются. После завершения партии нажмите «Ещё одну». Если окно результата закрыто, эта кнопка остаётся под доской.

Прогресс и текущая позиция сохраняются в `localStorage` этого браузера. Очистка данных сайта удаляет сохранение. Звук можно включить в верхнем меню. Сброс истории требует отдельного подтверждения внутри игры.

## Шахматная адаптация

Это собственный вариант гексагональных шахмат, а не точная реализация шахмат Глинского. Доска имеет радиус 4 и состоит из 61 клетки, координаты осевые `(q,r)`.

- Ладья ходит по шести направлениям через стороны гексов.
- Слон — по шести направлениям через вершины.
- Ферзь объединяет эти направления.
- Король делает один шаг через сторону или вершину.
- Конь прыгает на три шага, не по прямой: 12 возможных смещений.
- Белая пешка идёт в `(0,-1)`, берёт в `(-1,0)` и `(1,-1)`; чёрная движется зеркально. На противоположном краю автоматически превращается в ферзя.

Рокировки, взятия на проходе и начального двойного хода пешки нет. Шах и защита своего короля обязательны. Пат, голые короли, троекратное повторение и 50 полных ходов без взятий и ходов пешками дают ничью.

## Изменения правил

Изменения объявляются **между партиями**, действуют на обе стороны и накапливаются:

| После сыгранных партий | Новое правило |
| --- | --- |
| 3 | Пешки могут отступать и брать назад |
| 5 | Короли могут пройти две клетки через стороны; путь должен быть свободен и безопасен |
| 7 | Кони дополнительно получают один шаг через сторону |

Длинный ход короля расширяет и его зону контроля: две прямые клетки считаются атакованными, если промежуточная клетка свободна. Короли не могут сближаться в эту зону.

Сила ИИ растёт с числом побед; поражения не повышают сложность. ИИ работает в Web Worker, использует ограниченный поиск с оценкой материала и позиции. Это игровой соперник, а не движок турнирного уровня.

## Структура

- `dist/index.html`, `style.css`, `app.js` — интерфейс и игровой цикл.
- `dist/engine.js` — чистая логика ходов, шаха, мата, ничьих и ИИ.
- `dist/campaign.js` — прогресс, реплики и изменения правил.
- `dist/ai-worker.js` — расчёт ответного хода вне основного потока.
- `test/` — проверки правил, кампании и взаимодействия модулей.
- `.openai/hosting.json` — конфигурация статической публикации Sites.

Игра не требует сервера приложения, аккаунтов, внешнего API или ключей. Шрифт Golos Text загружается из Google Fonts; при отсутствии сети используется системный шрифт.
